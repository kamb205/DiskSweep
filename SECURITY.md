# Security

DiskSweep reads and removes files, so security and safety reports are taken seriously.

If you find a way DiskSweep could remove something it shouldn't, expose private data, or be misused by another app, please **don't open a public issue**. Instead, report it privately through [GitHub's private vulnerability reporting](https://github.com/kamb205/DiskSweep/security/advisories/new).

Please include the macOS version, what you did, and what happened. You'll get a reply as soon as possible.
