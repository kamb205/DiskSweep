# DiskSweep 1.0

The first public release of DiskSweep, a free, open-source cleaner and speed tool for macOS 26 Tahoe.

**Highlights**
- **Smart Care**: one click selects junk that's safe to remove (caches, logs, installers, build folders, repeat downloads).
- **Speed**: memory breakdown, Free Up Memory, auto-quit for inactive apps, Background Items and a Speed Settings checklist.
- **Cleanup**: System Junk, Developer Junk, AI Models, Installers, Downloads and Trash Bins.
- **Files**: Large and Old Files, Duplicates, Space Lens and Music & Stems.
- **Applications**: Uninstaller and App Leftovers.
- Menu bar panel and keyboard shortcuts.

**Install**
Download `DiskSweep-1.0.dmg` below, drag DiskSweep to Applications, then open it. The first time, macOS asks you to confirm: go to System Settings → Privacy & Security and click **Open Anyway**.

Requires macOS 26 Tahoe or later. Universal: Apple silicon and Intel.
